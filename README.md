# 🚩 picoCTF Solutions Repository

Organized, reproducible writeups and solution scripts for picoCTF challenges.  
Purpose: learn applied security, build a hiring portfolio, and share clear methods.

---

## 📂 Repository Structure

Each challenge folder contains:
- README.md — problem summary, approach, steps, and final flag.
- solve.py or equivalent — runnable script to reproduce the solution.
- notes.md — optional deeper analysis or references.
